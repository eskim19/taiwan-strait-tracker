# 양안 뉴스 트래커

대만해협 관련 보도를 **사건 단위로 묶고**, 그 사건이 몇 개의 **독립된 진영**에서 확인됐는지를 규칙으로 계산해 신뢰도 등급(A/B/C/D)으로 표시하는 정적 사이트. 여기에 대만 국방부가 매일 발표하는 PLA 활동 집계를 스크래핑해, 언론 노이즈와 무관한 객관 지표를 함께 보여준다.

서버가 없다. GitHub Actions가 주기적으로 수집해 JSON을 커밋하고, GitHub Pages가 그 JSON을 읽는 정적 페이지를 서빙한다.

---

## 이 트래커가 남들과 다른 점

**독립성을 매체 수가 아니라 진영으로 센다.** 환구시보·신화·CCTV가 같은 사건을 동시에 보도해도 그것은 독립된 세 증언이 아니라 한 정부의 한 발표다. 도메인 수로만 세면 관영매체 일제 보도가 최고 신뢰도를 받는 사고가 난다. `independent` 진영은 매체별로 세고, 국가 진영은 몇 곳이 보도하든 **1로만** 계산한다.

여기에 더해 **같은 원고를 여러 번 세지 않는다.** 로이터 기사 하나를 세 매체가 전재하면 도메인은 3개지만 증언은 하나다. 제목 토큰 containment(≥0.75)로 전재를 잡아 대표 하나만 센다. 대만 매체들이 국방부 발표 수치를 받아쓴 경우도 공유 숫자로 잡는다. 포털·재배포 사이트(야후·MSN·다음 등)는 아예 수집하지 않는다.

**임베딩 없이 교차언어 클러스터링을 한다.** 한국어 기사와 중국어 기사는 어휘 교집합이 0이라 코사인 유사도로는 영원히 묶이지 않는다. 다국어 별칭 사전(`collector/gazetteer.py`)으로 엔티티를 언어 중립 ID로 환원하고, 제목의 숫자를 함께 시그니처로 쓴다. 모든 매체가 국방부의 **같은 일일 집계**를 인용하기 때문에 `40機艦`과 `40 aircraft and ships`가 `n:40`이라는 거의 유일한 지문을 공유한다.

**병합을 여는 것은 사건 유형과 고유명뿐이다.** 요소별 순도를 실측해보면 `live_fire`는 빈도 28.9%에 순도 1.00인데 `pla`는 두 배 희귀하면서 순도 0.24다. 순도는 희귀도의 함수가 아니라서, IDF로 가중하면 완벽한 증거보다 유해한 증거를 더 신뢰하게 된다. 행위자·장소·장비는 같은 배우가 모든 사건에 등장하므로 사건을 식별하지 못한다. 그래서 `KIND` 표를 두고 EVENT·NAMED만 앵커로 삼는다(`ACTOR`를 허용하면 정밀도가 1.000 → 0.893으로 무너진다).

**LLM을 쓰지 않는다.** 전부 규칙 기반이라 판정 근거를 문자열로 그대로 노출할 수 있고, API 비용도 없다.

## 실행

```bash
pip install -r requirements.txt

python -m collector.fetch            # 피드 생존 진단 (좀비 피드 조기 탐지)
python -m collector.metrics          # 클러스터링 품질 게이트 — 코드 고치면 반드시
python -m collector.selfcheck        # 데이터 사실성 검사 (지표와 다른 질문을 한다)
python -m collector.mnd --backfill   # 국방부 집계 백필 — 최초 1회만 (약 150쪽)
python -m collector.build            # 전체 파이프라인
python -m http.server -d docs 8000   # http://localhost:8000
```

`collector.build` 옵션: `--skip-mnd`, `--skip-fetch`(재계산만), `--rebuild`(이전 사건·아카이브를 `.bak`으로 밀고 처음부터 — 클러스터링 규칙을 바꿨을 때 1회).

`collector.metrics` 옵션: `--robust`(80% 부분표본 20회 재추출).

## 구조

```
collector/
  feeds.py      피드 목록 + 출처 등급표 + 진영·계열 매핑 + 주제 게이트  ← 편집 대상은 대부분 여기
  fetch.py      requests+feedparser, 브라우저 UA, ETag, 피드별 예외 격리
  normalize.py  RSS 항목 → 통일 스키마, 언어 판정, 주제 필터, 제목 개정본 중복제거
  gazetteer.py  다국어 별칭 사전 + KIND(엔티티 종류) + 앵커 규칙
  cluster.py    언어 내 TF-IDF + 시그니처 겹침계수 병합(앵커 게이트)
  score.py      원고군 축약 → 신뢰도 등급·점수·근거 문자열, 사건 객체 조립
  mnd.py        대만 국방부 일일 PLA 집계 스크래퍼
  metrics.py    클러스터링 품질 측정 + 게이트
  selfcheck.py  데이터 사실성 검사 (품질이 아니라 '이게 사실인가')
  build.py      엔트리포인트
  tests/
    gold_2026_07.py        골드 라벨(다건 사건 25개)
    snapshot_2026_07.json  고정 코퍼스 196건 — 라벨과 짝. 임의 갱신 금지
docs/           GitHub Pages 루트 (빌드 도구 없음, 바닐라 JS)
  data/         수집 결과 JSON — Actions가 커밋한다
```

### 데이터 파일

| 파일 | 내용 |
|---|---|
| `docs/data/events.json` | 롤링 14일 사건 클러스터 |
| `docs/data/tension.json` | 국방부 일일 집계 (누적 전체, 절대 덮어쓰지 않음) |

| `docs/data/build_meta.json` | 수집 상태·피드별 성공/실패·정체 여부·미분류 도메인 승격 대기열 |
| `docs/data/archive/YYYY-MM.json` | 월별 아카이브 |

## 신뢰도 등급 규칙

독립 진영 수 = (`independent` 진영의 서로 다른 도메인 수) + (등장한 국가 진영 종류 수)

| 등급 | 조건 |
|---|---|
| **A 검증됨** | 독립 진영 3곳 이상 + 통신사·공영방송 또는 분석기관 포함 |
| **B 개연적** | 독립 진영 2곳, 또는 통신사·공영방송 단독 보도 |
| **C 단일 출처** | 독립 출처 한 곳, 교차 확인 없음 |
| **D 미교차** | 사유별로 문구가 갈린다 — 발표 단독 / 출처 미확인 / 성향 단독 |

D는 보도가 틀렸다는 뜻이 아니라 **발표 주체 밖의 확인이 아직 없다**는 뜻이다.

정렬용 점수: `50×evidence + 24×min(독립,4)/4 + 11×교차언어 + 7×1차출처인용 + 8×보도지속`.
`evidence`는 독립 출처들의 등급을 수확체감으로 합산한다(같은 출처는 한 번만 센다) — 최고 등급 하나만 보면 `T1+T1`과 `T1+T5`가 같은 점수가 되기 때문이다. 죽어 있던 두 항(전언 비율 0/128, 대립진영 0/95)은 제거했다.

UI에는 점수보다 **근거 문자열**을 앞세운다. 숫자만 보여주면 없는 정밀도를 오해한다.

## 출처를 추가하거나 등급을 고치려면

`collector/feeds.py` 한 파일만 고치면 된다. 코드 변경 없음.

- **피드 추가** → `FEEDS` 리스트에 한 항목. 전 섹션 피드면 `needs_filter: True`.
- **등급 조정** → `SOURCES` 딕셔너리 (`도메인: (등급, 진영, 표시명, 편향메모)`).
- **새 엔티티** → `collector/gazetteer.py`의 `ENTITIES`에 한 줄. 새 함정·훈련명·인물이 나오면 여기 넣는 즉시 교차언어 병합이 된다.

## 운영 중 알아둘 것

**Google News 쿼리에 괄호 중첩이나 `AND`를 쓰면 안 된다.** 최신순 랭킹이 깨지고 관련도 정렬로 빠져 한 달 지난 기사만 돌아온다(2026-07-27 실측 확인). 인용구의 단순 `OR` 나열만 쓸 것. 링크는 `news.google.com/rss/articles/...` 불투명 리다이렉트이므로 **디코딩을 시도하지 말고**, 매체 도메인은 각 항목의 `<source url>` 태그에서 뽑는다.

**죽은 피드.** Reuters(2020년 공개 RSS 폐지)·AP·CNN·Kyodo는 자체 RSS가 없거나 죽었다. Google News 경유로만 들어온다. 신화통신 영문 피드는 XML은 응답하지만 최신 항목이 2018년 1월인 좀비다. `python -m collector.fetch`가 최신 항목이 7일보다 오래된 피드를 `[정체]`로 표시하니 주기적으로 확인할 것.

**대만 국방부 TLS.** Python 3.13부터 기본 SSL 컨텍스트가 `VERIFY_X509_STRICT`를 켜는데, mnd.gov.tw 인증서에 Subject Key Identifier 확장이 없어 여기서 막힌다. `fetch.make_session()`이 인증서 체인·호스트명 검증은 유지한 채 이 검사만 완화한다. `verify=False`가 아니다.

**스케줄 워크플로 자동 비활성화.** GitHub는 레포가 60일간 활동이 없으면 스케줄 워크플로를 끈다. 봇 커밋은 활동으로 인정되지 않을 수 있다. 멈춘 것 같으면 Actions 탭에서 수동 `Run workflow`로 되살린다.

**미병합 > 과병합.** 클러스터 병합 임계는 보수적으로 잡혀 있다. 과병합은 없는 교차검증을 만들어내 등급을 조작하는 셈이라, 사건이 쪼개져 보이는 미병합보다 훨씬 해롭다.

**사건이 쪼개지면 임계값이 아니라 EVENT 엔티티를 한 줄 추가한다.** 임계값을 만지면 반대쪽이 조용히 터진다. `python -m collector.metrics` 게이트(BCubed F1 ≥ 0.80, 혼입 ≤ 2, 파편화 ≤ 6)와 `python -m collector.selfcheck` 를 통과하는지 반드시 확인할 것. 클러스터링·등급 규칙을 바꿨으면 배포 시 `--rebuild`를 한 번 돌려야 한다 — 사건 ID가 전부 바뀌는데 옛 카드가 14일(아카이브는 영구) 남는다.

**지표가 통과했다는 것과 데이터가 옳다는 것은 다른 명제다.** 한 번 크게 데였다 — 파편화·BCubed 가 전부 좋아진 회차에 국방부 시계열의 41%가 조용히 사라졌다. `collector/metrics.py` 는 클러스터링 *품질*을, `collector/selfcheck.py` 는 *사실성*(시계열 연속성·기사 중복 노출·숫자 지문 환각·제목 절단·게이트 리콜)을 본다. 새 결함을 찾을 때마다 "어떤 검사가 이걸 잡았을까"를 묻고 selfcheck 에 추가할 것.

**국방부는 보고 문구를 바꾼다.** 실제로 세 가지 형식을 겪었다. 2024년형은 `27 PLA aircraft and 7 PLAN vessels`, 2026년형은 `3 sorties of PLA aircraft, 7 PLAN ships and 4 official ships`, 2022년 11월 이전은 남서 ADIZ만 다루는 **다른 보고서**라 이 지수에 넣으면 안 된다(실측 경계: 150쪽=2022-11-24 성공 / 152쪽=2022-10-30 실패). 따라서 2022년 8월 펠로시 위기는 범위 밖이다. `parse_detail`은 숫자를 실제로 하나라도 뽑았을 때만 `parse_ok`를 준다. 이 방어가 없던 시절 2년치가 0으로 쌓여 기준선 중앙값을 무너뜨렸고 '평소 대비 113배' 같은 헛수치가 나왔다. 백필 로그에 `집계 문장 없음`이 대량으로 찍히면 형식이 또 바뀐 것이다.

## GitHub Pages 설정

레포 Settings → Pages → Source를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/docs`로 지정. 별도 배포 스텝이 없다.

## 한계

- 자동 분류라 오분류가 있다. 등급은 보도의 **검증 정도**를 뜻할 뿐 사실 여부를 보증하지 않는다.
- 출처 등급표는 판단이 들어간 데이터다. `sources.json`으로 전부 노출되니 동의하지 않으면 고쳐 쓰면 된다.
- 중국 관영매체와 대만 매체는 애초에 서로 다른 사건을 기사로 만든다. 그래서 '관점 대조' 화면은 같은 사건 짝짓기를 강요하지 않고 양측 스트림을 나란히 놓는다. 두 열이 다른 것을 다루고 있다는 사실 자체가 관찰 대상이다.
- 공개 RSS와 공개 웹페이지만 사용한다. 유료 API·소셜미디어·비공개 소스는 쓰지 않는다.
