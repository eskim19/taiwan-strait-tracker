# 양안 뉴스 트래커

대만해협 관련 보도를 **사건 단위로 묶고**, 그 사건이 몇 개의 **독립된 진영**에서 확인됐는지를 규칙으로 계산해 신뢰도 등급(A/B/C/D)으로 표시하는 정적 사이트. 여기에 대만 국방부가 매일 발표하는 PLA 활동 집계를 스크래핑해, 언론 노이즈와 무관한 객관 지표를 함께 보여준다.

서버가 없다. GitHub Actions가 주기적으로 수집해 JSON을 커밋하고, GitHub Pages가 그 JSON을 읽는 정적 페이지를 서빙한다.

---

## 이 트래커가 남들과 다른 점

**독립성을 매체 수가 아니라 진영으로 센다.** 환구시보·신화·CCTV가 같은 사건을 동시에 보도해도 그것은 독립된 세 증언이 아니라 한 정부의 한 발표다. 도메인 수로만 세면 관영매체 일제 보도가 최고 신뢰도를 받는 사고가 난다. 이 트래커는 `independent` 진영은 매체별로 세고, `prc_state`·`tw_state`·`us_gov` 같은 국가 진영은 몇 곳이 보도하든 **1로만** 계산한다. 포털·재배포 사이트(야후·MSN·다음 등)는 원 매체 기사를 실어 나를 뿐이라 아예 수집하지 않는다.

**임베딩 없이 교차언어 클러스터링을 한다.** 한국어 기사와 중국어 기사는 어휘 교집합이 0이라 코사인 유사도로는 영원히 묶이지 않는다. 대신 다국어 별칭 사전(`collector/gazetteer.py`)으로 엔티티를 언어 중립 ID로 환원한 뒤, 제목에서 뽑은 숫자를 함께 시그니처로 쓴다. 이 도메인에서 유독 잘 먹히는 이유는 모든 매체가 국방부의 **같은 일일 집계**를 인용하기 때문이다 — `40機艦`과 `40 aircraft and ships`가 `n:40`이라는 거의 유일한 지문을 공유한다.

**LLM을 쓰지 않는다.** 전부 규칙 기반이라 판정 근거를 문자열로 그대로 노출할 수 있고, API 비용도 없다.

## 실행

```bash
pip install -r requirements.txt

python -m collector.fetch            # 피드 생존 진단 (좀비 피드 조기 탐지)
python -m collector.mnd --backfill   # 국방부 집계 백필 — 최초 1회만
python -m collector.build            # 전체 파이프라인
python -m http.server -d docs 8000   # http://localhost:8000
```

`collector.build` 옵션: `--skip-mnd`(국방부 건너뛰기), `--skip-fetch`(수집 건너뛰기, 재계산만).

## 구조

```
collector/
  feeds.py      피드 목록 + 출처 등급표 + 진영 매핑 + 주제 게이트  ← 편집 대상은 대부분 여기
  fetch.py      requests+feedparser, 브라우저 UA, ETag, 피드별 예외 격리
  normalize.py  RSS 항목 → 통일 스키마, 언어 판정, 주제 필터
  gazetteer.py  다국어 별칭 사전 (교차언어 병합의 핵심 자산)
  cluster.py    언어 내 TF-IDF + 시그니처 기반 교차언어 병합
  score.py      신뢰도 등급·점수·근거 문자열, 사건 객체 조립
  mnd.py        대만 국방부 일일 PLA 집계 스크래퍼
  build.py      엔트리포인트
docs/           GitHub Pages 루트 (빌드 도구 없음, 바닐라 JS)
  data/         수집 결과 JSON — Actions가 커밋한다
```

### 데이터 파일

| 파일 | 내용 |
|---|---|
| `docs/data/events.json` | 롤링 14일 사건 클러스터 |
| `docs/data/tension.json` | 국방부 일일 집계 (누적 전체, 절대 덮어쓰지 않음) |
| `docs/data/sources.json` | 출처 등급표 — UI 범례에서 판정 근거 확인용 |
| `docs/data/build_meta.json` | 수집 상태·피드별 성공/실패 |
| `docs/data/archive/YYYY-MM.json` | 월별 아카이브 |

## 신뢰도 등급 규칙

독립 진영 수 = (`independent` 진영의 서로 다른 도메인 수) + (등장한 국가 진영 종류 수)

| 등급 | 조건 |
|---|---|
| **A 검증됨** | 독립 진영 3곳 이상 + 통신사·공영방송 또는 분석기관 포함 |
| **B 개연적** | 독립 진영 2곳, 또는 통신사·공영방송 단독 보도 |
| **C 단일 출처** | 출처 한 곳, 교차 확인 없음 |
| **D 주의** | 한쪽 정부 발표만 존재하거나, 성향·미분류 매체 단독이거나, 전언 표현이 과반 |

정렬용 점수: `45×등급가중 + 35×min(독립진영,4)/4 + 20×1차출처인용 − 10×전언비율` (+5: 중국·대만 양측 모두 보도)

UI에는 점수보다 **근거 문자열**을 앞세운다. 숫자만 보여주면 없는 정밀도를 오해한다.

## 출처를 추가하거나 등급을 고치려면

`collector/feeds.py` 한 파일만 고치면 된다. 코드 변경 없음.

- **피드 추가** → `FEEDS` 리스트에 한 항목. 전 섹션 피드면 `needs_filter: True`.
- **등급 조정** → `SOURCES` 딕셔너리 (`도메인: (등급, 진영, 표시명, 편향메모)`).
- **새 엔티티** → `collector/gazetteer.py`의 `ENTITIES`에 한 줄. 새 함정·훈련명·인물이 나오면 여기 넣는 즉시 교차언어 병합이 된다.

## 운영 중 알아둘 것

**Google News 쿼리에 괄호 중첩이나 `AND`를 쓰면 안 된다.** 최신순 랭킹이 깨지고 관련도 정렬로 빠져 한 달 지난 기사만 돌아온다(2026-07-27 실측 확인). 인용구의 단순 `OR` 나열만 쓸 것. 링크는 `news.google.com/rss/articles/...` 불투명 리다이렉트이므로 **디코딩을 시도하지 말고**, 매체 도메인은 각 항목의 `<source url>` 태그에서 뽑는다.

**죽은 피드.** Reuters(2020년 공개 RSS 폐지)·AP·CNN·Kyodo는 자체 RSS가 없거나 죽었다. Google News 경유로만 들어온다. 신화통신 영문 피드는 XML은 응답하지만 최신 항목이 2018년 1월인 좀비다. `python -m collector.fetch`가 최신 항목이 7일보다 오래된 피드를 `[정체]`로 표시하니 주기적으로 확인할 것.

**대만 국방부 TLS.** Python 3.13부터 기본 SSL 컨텍스트가 `VERIFY_X509_STRICT`를 켜는데, mnd.gov.tw 인증서에 Subject Key Identifier 확장이 없어 여기서 막힌다. `fetch.make_session()`이 인증서 체인·호스트명 검증은 유지한 채 이 검사만 완화한다. `verify=False`가 아니다.

**스케줄 워크플로 자동 비활성화.** GitHub는 레포가 60일간 활동이 없으면 스케줄 워크플로를 끈다. 봇 커밋은 활동으로 인정되지 않을 수 있다. 멈춘 것 같으면 Actions 탭에서 수동 `Run workflow`로 되살린다.

**미병합 > 과병합.** 클러스터 병합 임계는 보수적으로 잡혀 있다. 과병합은 없는 교차검증을 만들어내 등급을 조작하는 셈이라, 사건이 쪼개져 보이는 미병합보다 훨씬 해롭다. 임계를 낮출 때는 이 점을 기억할 것.

## GitHub Pages 설정

레포 Settings → Pages → Source를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/docs`로 지정. 별도 배포 스텝이 없다.

## 한계

- 자동 분류라 오분류가 있다. 등급은 보도의 **검증 정도**를 뜻할 뿐 사실 여부를 보증하지 않는다.
- 출처 등급표는 판단이 들어간 데이터다. `sources.json`으로 전부 노출되니 동의하지 않으면 고쳐 쓰면 된다.
- 중국 관영매체와 대만 매체는 애초에 서로 다른 사건을 기사로 만든다. 그래서 '관점 대조' 화면은 같은 사건 짝짓기를 강요하지 않고 양측 스트림을 나란히 놓는다. 두 열이 다른 것을 다루고 있다는 사실 자체가 관찰 대상이다.
- 공개 RSS와 공개 웹페이지만 사용한다. 유료 API·소셜미디어·비공개 소스는 쓰지 않는다.
